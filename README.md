# 🌍 Global Energy Consumption vs Production (1980–2020) | Power BI Dashboard

This repository contains an interactive Power BI dashboard that visualizes the **Global Energy Consumption vs. Production** from 1980 to 2020. The dataset includes energy sources such as **coal, natural gas, petroleum, fossil fuels, nuclear, and renewable energy** across different continents and countries.

## 📊 Dashboard Highlights

- Year-wise comparison of global **energy production vs. consumption** (1980–2020)
- Breakdown of energy by type: **Coal, Natural Gas, Petroleum, Nuclear, Renewables, and Fossil Fuels**
- **Continent-wise and Country-wise** energy consumption and production
- Trend analysis showing the shift towards **renewable and nuclear energy**

## 📁 Dataset Information

- **Source:** Github repo
- **Years Covered:** 1980–2020
- **Metrics:** Energy production and consumption (in exajoules, terawatt-hours, etc.)
- **Granularity:** Global, Continent, and Country-level
  
## 📌 Tools & Technologies Used

- **Power BI** – for data visualization and dashboard creation

## 🚀 How to Use

1. Clone the repository
2. Open the `.pbix` file in **Power BI Desktop**
3. Explore the dashboard interactively or publish it to Power BI service.
